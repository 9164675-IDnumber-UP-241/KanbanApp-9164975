# Навчальний Android-проєкт (покрокова розробка)

Цей репозиторій демонструє поступову побудову Android-застосунку.  
Кожен етап розвитку збережений у вигляді окремого **коміту** та **тегу** (`step-01`, `step-02`, ...).

## Як отримати проєкт

### Через Android Studio
1. Відкрити **Get from VCS**
2. Вставити URL репозиторію
3. Натиснути **Clone**

## Як переглядати етапи

### Через Android Studio
1. Відкрити проєкт
2. Перейти в **Git → Show History** або вкладку **Git Log**
3. Обрати потрібний коміт або тег
4. Виконати **Checkout**

### Через термінал

Показати всі етапи:
```bash
git tag
```

Перейти на етап:
```bash
git checkout step-03
```

## Після переходу на інший етап

В Android Studio:
- виконати **Gradle Sync** (якщо потрібно)
- за потреби: **Rebuild Project**

## Як повернутися до актуальної версії

```bash
git checkout master
```

## Як порівнювати етапи

```bash
git diff step-02 step-03
```

## Рекомендований порядок роботи

1. Перейти на `step-01`
2. Запустити проєкт
3. Перейти на `step-02`
4. Подивитися, що змінилося
5. Повторити для наступних етапів

## Корисні команди

```bash
git log --oneline     # історія комітів
git tag               # список етапів
git checkout step-01  # перейти на етап
git checkout master   # повернутися назад
```

## Ідея проєкту

Цей репозиторій — це не просто код, а **історія розвитку застосунку**.  
Вивчайте його поетапно.
